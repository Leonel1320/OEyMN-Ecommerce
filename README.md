
# 🛒 E-commerce de Hardware con Asesoramiento Avanzado

**Este proyecto es una tienda en línea especializada en hardware de alto rendimiento**, orientada a estudiantes, profesionales y entusiastas que buscan **asesoramiento experto para elegir sus componentes o equipos tecnológicos**.

Ofrecemos una amplia gama de productos, incluyendo:

- 💻 Equipos reacondicionados como nuevos  
- 🖥️ Componentes de computadoras (CPU, GPU, RAM, SSD, etc.)  
- 🛠️ Accesoramiento técnico personalizado

El sitio está desarrollado con **React y Vite** y sigue la metodología **Scrum** para una organización ágil y eficiente del proyecto.

---

## 📌 Tecnologías utilizadas

- ⚛️ React
- ⚡ Vite
- 🌐 React Router DOM
- 🎨 Tailwind CSS (o CSS puro)
- 💾 localStorage
- 📦 npm

## 🔁 Metodología Scrum

Este proyecto sigue la metodología **Scrum**, dividido en 4 Sprints.  
Las tareas están gestionadas en la sección **Issues** y **Projects** del repositorio.

---

## 📅 Sprints

### 🧩 Sprint 1: Configuración y estructura base
- Inicializar proyecto con Vite + React
- Instalar dependencias básicas
- Crear estructura de carpetas
- Implementar rutas principales
- Crear layout base con Header y Footer
- Maquetar la página de inicio

### 🛒 Sprint 2: Catálogo y carrito
- Componente de productos en grilla
- Página de detalle de producto
- Lógica del carrito (añadir/eliminar)
- Guardar en localStorage
- Mostrar totales

### 🔐 Sprint 3: Autenticación y checkout
- Formulario de login/registro
- Simulación de autenticación
- Proteger rutas
- Formulario de dirección en checkout
- Validaciones

### 🧼 Sprint 4: Extras y pulido final
- Estilo responsivo
- Mensajes de éxito/error
- Simulación de orden confirmada
- Búsqueda y filtrado
- Documentación
- Deploy
